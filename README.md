# Kalorix Fitatu (v2) 🥗🔥

Nowoczesna, minimalistyczna i czytelna aplikacja do liczenia kalorii i makroskładników inspirowana Fitatu.

## ✨ Kluczowe Funkcje

- 🍗 **Pełne, czytelne nazwy makroskładników**: Zamiast skrótów B/T/W zawsze pełne opisy: **Białko**, **Tłuszcz**, **Węglowodany** oraz **Kalorie** z dokładnymi gramaturami.
- 🎨 **Minimalistyczny Design 1:1**: Wyraźna, czarna i kontrastowa czcionka w polach tekstowych ("Szukaj produktu...", notatki), estetyczne karty posiłków i zaokrąglone elementy.
- ⚖️ **Wpisywanie ilości PRZED dodaniem**: Dynamiczny kalkulator gramatury przeliczający makroskładniki na żywo z szybkimi przyciskami (25g, 50g, 100g, 150g, 200g, 1 sztuka).
- 📅 **Kalendarz Dzienny & Tygodniowy**: Pasek 7 dni tygodnia, nawigacja dzień po dniu oraz selektor daty.
- 📸 **Skaner AI (Zdjęcie + Notatka Kontekstowa)**: Możliwość zrobienia zdjęcia (np. paczka orzeszków, kubek herbaty) i dopisania własnej notatki dla AI (np. *"Do herbatki dodałem 2 łyżki cukru"* lub *"Zjadłem pół paczki"*).
- 🥗 **Baza Przepisów Fit**: Gotowe zbilansowane przepisy z czasem przygotowania, składnikami, instrukcją i możliwością dodania całego przepisu do wybranego posiłku 1-kliknięciem.
- 💧 **Licznik Wody**: Kontrola dziennego nawodnienia z szybkimi przyciskami dodawania szklanki/butelki.
- 🔑 **Obsługa Kluczy OpenRouter AI**: Bezpieczne rotowanie kluczy w przeglądarce + inteligentny tryb offline.

## 🚀 Uruchomienie lokalne

```bash
npm install
npm run dev
```

Aplikacja uruchomi się pod adresem `http://localhost:3000`.
